# Balkon Halısı Silkeleme Koordinatörü

## Resmî Beyanname

Bu yazılım, site yönetim kurulu, apartman kâhyası, alt kat komşusu ve rüzgârın ortak mutabakatıyla geliştirilmiştir. Amacı, pazar sabahı 09:17 ile 09:23 arasında gerçekleşen kaotik halı silkeleme faaliyetlerini **uluslararası ISO-HALI-2026** standardına bağlamaktır.

Halı silkelemek bir hobi değildir. Bir kamu düzeni meselesidir.

## Neden Bu Proje Hayatî Önemdedir?

- Alt katın balkonuna düşen tüy, diplomatik krize dönüşebilir.
- Aynı anda iki dairenin silkelemesi atmosferik rezonans yaratır.
- Bilim insanları (biz) bu rezonansı henüz ölçememiştir; ölçememek, yoktur demek değildir.
- Çay demlenirken silkelemek, çayın ruhunu incitir.

## Kurulum

```bash
python3 silkele.py
```

Bağımlılık yoktur. Python 3 yeter. Komşu rızası tavsiye edilir ama zorunlu değildir (hukuken tartışmalıdır).

## Kullanım

Program sizden:
1. Kat numaranızı
2. Halının tahmini yaşını
3. Alt katın o anda evde olup olmadığını

sorar. Ardından size **resmî silkeleme penceresi** tahsis eder. Pencere 4 ila 11 saniye sürer. Bu sürede silkelemezseniz sıra komşuya geçer. İtiraz hakkınız vardır; itiraz da kuyruğa girer.

## Mimari

Tek dosya. Tek gerçek. Çok toz.

## Sorumluluk Reddi

- Halının düşmesinden bu depo sorumlu değildir.
- Komşunun bağırmasından bu depo sorumlu değildir.
- Site yönetiminin tutanak tutmasından bu depo gurur duyar.
